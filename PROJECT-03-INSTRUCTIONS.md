# Project-03: Inventory Management System — Report Template and Submission Instructions

Deadline: 25-06-2026

Students must prepare a detailed Word report explaining the project and the code implementation. Submit the report in MS Word (.docx) along with your source code files.

Template headings (each section should contain sufficient detail):

1. Project Title
2. Objective of the Project
3. Problem Statement
4. Software Requirements
   - OS, MySQL version, MySQL Workbench, required libraries/tools
5. Flowchart / Block Diagram
   - Insert ER diagram and workflow diagrams
6. Source Code with Explanation
   - Provide the main files and explain key functions/classes
7. Description of Each Module/Function
   - Module purpose, inputs, outputs, error handling
8. Input and Output Results
   - Example inputs, screenshots, sample query outputs
9. Screenshots or Photographs
   - UI screenshots, Workbench model, terminal outputs
10. Challenges Faced and Solutions
11. Conclusion
12. Future Scope
13. References (if any)
14. Appendix: SQL scripts and sample data file names:
    - ims_schema.sql
    - ims_sample_data.sql
    - ims_er.dot

Notes on academic honesty:
- Make sure the report is your own work. Do not copy from others or from the internet.
- Cite any resources you used.

How to convert this Markdown to Word (.docx):
- Install Pandoc (https://pandoc.org/installing.html).
- Run: pandoc PROJECT-03-INSTRUCTIONS.md -o Project_03_Report_Template.docx
- Open and edit the .docx in MS Word to add diagrams and screenshots.

Submission:
- Zip the Word report + source code folder (SQL scripts + any application code).
- Filename example: Project03_<StudentName>_<RollNo>.zip
